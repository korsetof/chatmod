# Contributing to ChatMod

Thanks for contributing.

## Workflow

1. Create a focused branch from `main`.
2. Keep changes small and easy to review.
3. Run `npm run check` before opening a pull request.
4. Update documentation when behavior or configuration changes.
5. Never commit secrets, credentials or production infrastructure details.

## Pull requests

A good PR should explain:
- what changed;
- why it changed;
- how it was tested;
- any migration or deployment impact.

Please use the pull request template.
